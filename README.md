# How Intentional Is Your Child's Educational Strategy?

Лендинг с адаптивным тестом из 7 вопросов для родителей детей 4–18 лет.
Каждый вопрос показывается на отдельном экране (шаге), в конце теста
пользователь указывает почту, и туда приходит расшифровка результата.
Весь пользовательский текст — на английском (лендинг для англоязычной
аудитории).

Реализовано на React + Vite как самостоятельный проект в собственном
репозитории — никак не связан с другими проектами.

## Как это устроено

- `src/data/questions.js` — все тексты теста: 4 возрастных блока по
  7 вопросов, шкала ответов, общая и тематическая расшифровка.
- `src/data/quotes.js` — цитаты педагогов, по одной на каждом экране.
- `src/logic/scoring.js` — подсчёт баллов и логика выбора приоритетных
  рекомендаций (правило приоритета, предупреждение о нагрузке при слабом
  ответе на вопрос 7).
- `src/App.jsx` — весь пользовательский сценарий: стартовый экран → выбор
  возраста → инструкция → 7 вопросов (каждый — отдельный «экран»,
  переключение отражается в адресной строке через `#hash`, поддерживается
  кнопка «Назад» браузера) → форма с почтой → экран результата.
- `src/firebase.js` — сохраняет прохождение в Firestore
  (`quiz_submissions`) как внутренний лог. Письма он больше не отправляет —
  этим занимается MailerLite.
- `src/mailerlite.js` — отправляет email и данные результата в MailerLite
  (см. ниже).

## MailerLite: сбор контактов и письмо с расшифровкой

**Universal-скрипт аккаунта** (account `2568725`) уже подключён в
`index.html` — он идентифицирует сайт для MailerLite (трекинг, показ
попапов, настроенных в личном кабинете). Сам по себе он не умеет
отправлять произвольные кастомные поля — у MailerLite нет
задокументированного JS-метода для этого, — поэтому за фактическую
передачу email и посчитанного результата отвечает отдельный механизм
ниже.

Интеграция без бэкенда: при отправке формы `src/mailerlite.js`
POST-запросом (через скрытую форму + iframe, ровно так же, как это делает
собственный embed-виджет MailerLite) отправляет email и посчитанный
результат в MailerLite. Секретный API-ключ нигде не участвует — вызов
идёт напрямую из браузера на публичный form endpoint, поэтому это
безопасно даже без сервера.

**Ограничение этого способа:** отправка идёт в скрытый iframe, поэтому
приложение не может узнать, прошла ли она успешно — оно просто считает,
что письмо ушло. Если нужна гарантия и обработка ошибок, это уже другой
подход (через сервер с приватным API-ключом), не тот, что реализован
здесь.

Форма и её ID (`195474036978878332`, аккаунт `2568725`) уже созданы и
прописаны в `src/mailerlite.js` — код в этом файле POST-ит именно на тот
endpoint, который сгенерировал сам MailerLite для этой формы
(`https://assets.mailerlite.com/jsonp/2568725/forms/195474036978878332/subscribe`),
так что менять там ничего не нужно.

### Настройка (один раз, в личном кабинете MailerLite)

1. **Создайте кастомные поля** (Subscribers → Custom fields) со следующими
   ключами (тип — Text, кроме `total_score` — Number). Без них MailerLite
   просто проигнорирует эти значения в запросе:

   | Ключ поля         | Что туда попадает                                  |
   |--------------------|-----------------------------------------------------|
   | `age_group`        | id возрастного блока, например `7-10`                |
   | `age_label`        | подпись возраста, например `Ages 7–10`                |
   | `total_score`       | итоговый балл, 0–21                                 |
   | `level_title`       | заголовок уровня результата                          |
   | `level_text`        | описание уровня результата                           |
   | `priority_note`     | предупреждение о правиле приоритета (может быть пусто) |
   | `recommendation_1`  | первая рекомендация (может быть пусто)               |
   | `recommendation_2`  | вторая рекомендация (может быть пусто)               |
   | `recommendation_3`  | третья рекомендация (может быть пусто)               |

2. **Создайте автоматизацию** (Automations → New automation):
   триггер **«Subscriber joins a group»** → выбрать группу, привязанную к
   этой форме → действие **«Send email»**. В письме используйте
   мердж-теги полей выше, например:

   ```
   Subject: Your results: {$level_title}

   Hi,

   Here's what came back for your child ({$age_label}):

   {$level_title} — {$total_score} of 21 points
   {$level_text}

   {$priority_note}

   What to focus on first:
   {$recommendation_1}
   {$recommendation_2}
   {$recommendation_3}

   Questions to reflect on:
   — Which two areas matter most for your child right now?
   — Which current activities are actually helping develop those areas?
   — What could you drop, simplify, or move to protect interest, free
     time, and emotional well-being?
   ```

   Пустые `recommendation_N` в письме останутся просто пустой строкой —
   это нормально: у части результатов рекомендаций меньше трёх.

Форма и endpoint уже подключены, так что подписчики с email и всеми
посчитанными полями начнут попадать в MailerLite сразу после деплоя. Но
пока не созданы кастомные поля и автоматизация из шагов выше, реального
письма с расшифровкой подписчик не получит — просто добавится в список.

## Разработка

```bash
npm install
npm run dev
```

## Деплой

**GitHub Pages** — уже настроен: `.github/workflows/deploy-pages.yml`
собирает и публикует `dist/` при каждом пуше в `main`. Единственное, что
нужно сделать один раз в самом репозитории: **Settings → Pages → Build
and deployment → Source: GitHub Actions**. После этого сайт будет
доступен на `https://<владелец>.github.io/education-strategy-quiz/`.

**Vercel** — тоже подходит: Import Project → выбрать
`education-strategy-quiz`, `vercel.json` и `vite.config.js` уже
настроены, дополнительных параметров не нужно.
